# Старт

Адаптивная платформа для начинающих специалистов. В каталоге закреплены два профиля, указанные владельцем сайта; новые анкеты создаются через форму и сохраняются в `localStorage` этого браузера. В форме можно указать возраст и загрузить фотографию (JPG, PNG или WebP); изображение уменьшается перед локальным сохранением. Сохранённые профили, приглашения и история подбора также хранятся в `localStorage`.

## Запуск

Для просмотра без AI можно открыть `index.html` прямо в браузере. Для полноценной AI-интеграции нужен Go 1.21+ и ключ API провайдера, совместимого с форматом OpenAI Chat Completions.

Из папки `junior-match` задайте ключ в окружении и запустите сервер:

```powershell
$env:OPENAI_API_KEY = "ваш ключ"
go run server.go
```

Откройте `http://localhost:8080`. Ключ не передаётся браузеру и не сохраняется в исходниках. Можно задать `OPENAI_MODEL` (по умолчанию `gpt-4o-mini`), `OPENAI_BASE_URL` (по умолчанию `https://api.openai.com/v1/chat/completions`) и `PORT`.

## AI API

Встроенный мастер задаёт работодателю шесть последовательных вопросов о желаемом профиле сотрудника: направление и качества, навыки, время на обучение, график, бюджет и приоритет между мотивацией и базовыми знаниями. Работодатель описывает критерии кандидата, а не рабочую задачу или обязанности. После ответов интерфейс отправляет `POST /api/ai/match` с JSON вида:

```json
{
  "answers": { "criteria": "...", "skills": ["..."], "learning": "...", "schedule": "...", "budget": "...", "priority": "..." },
  "candidates": [{ "id": 1, "name": "...", "role": "...", "skills": ["..."], "project": "...", "match": 82 }]
}
```

Сервер просит модель ранжировать переданных кандидатов только по навыкам, проектам и ответам работодателя. Ожидается ответ `{"candidates":[{"id":1,"match":94,"explanation":"Есть похожий учебный проект и нужные навыки."}]}`. Если ключ или API недоступны, мастер использует локальный алгоритм и остаётся рабочим.
